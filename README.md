# uacKR 뱅크 생성기

스타크래프트 2 유즈맵 **언데드 어썰트 크로니클(Undead Assault Chronicles:KR)** 의 뱅크(`UAC.SC2Bank`)를 수정하거나 새로 만드는 웹 프로그램입니다.

> ⚠️ **사용 시 발생하는 모든 불이익은 사용자 본인에게 있습니다.**
> 맵 제작자나 블리자드의 공식 프로그램이 아니며, 뱅크 초기화·제재 등 어떠한 불이익도 책임지지 않습니다. 사용 전 원래 뱅크를 꼭 백업하세요.

## 바로 사용하기

👉 **[uacKR 뱅크 생성기 열기](./index.html)**

설치 없이 브라우저에서 바로 쓸 수 있습니다. 입력한 내용은 어디로도 전송되지 않습니다.

## 지원 범위

- 최신 버전 맵의 뱅크만 지원합니다. 예전 버전 뱅크는 불러올 수 없습니다.
- 맵이 업데이트되면 뱅크 구조가 바뀔 수 있습니다. 업데이트 후에는 정상 작동하는지 먼저 확인하세요.

## 사용 방법

1. 뱅크 파일을 백업합니다.
   `내 문서\StarCraft II\Accounts\숫자폴더\내핸들\Banks\제작자핸들\UAC.SC2Bank`
2. 생성기를 열고 **내 핸들**과 **제작자 핸들**을 입력합니다. 두 값은 뱅크 파일 경로의 폴더 이름에서 확인할 수 있습니다.
3. **기존 뱅크 파일 열기**로 지금 쓰는 뱅크를 불러옵니다.
4. 계급·전적, 모드별 기록, 해금 항목을 수정합니다.
5. **뱅크 만들기** → **UAC.SC2Bank 저장**을 누릅니다.
6. 저장한 파일로 원래 뱅크를 덮어씁니다.

자세한 내용은 [사용법.txt](./사용법.txt)를 참고하세요.

## 처음 한 번은 서명 확인

게임은 뱅크를 불러올 때 서명을 검사합니다. 제작자 핸들을 입력한 뒤 게임이 저장한 원래 뱅크를 불러와서 **"서명 공식 일치 확인"** 이 뜨는지 확인하세요. **"서명 불일치"** 가 뜨면 사용하지 마세요.
