UAC 뱅크 생성기 사용법
==================================================
 
언데드 어썰트 크로니클(Undead Assault Chronicles:KR) 뱅크를
수정하거나 새로 만드는 프로그램입니다.
 
- 설치 없이 uac-bank-generator.html 파일만 열면 바로 쓸 수 있습니다.
- 인터넷이 없어도 작동하고, 입력한 내용은 어디로도 전송되지 않습니다.
- 최신 버전 맵의 뱅크만 지원합니다. 예전 버전 뱅크는 불러올 수 없습니다.
 
 
■ 사용 전 꼭 하세요: 뱅크 백업
--------------------------------------------------
 
덮어쓰기 전에 원래 뱅크 파일을 다른 곳에 복사해 두세요.
문제가 생기면 그 파일로 되돌리면 됩니다.
 
[뱅크 파일 위치]
 
  내 문서\StarCraft II\Accounts\숫자폴더\내핸들\Banks\제작자핸들\UAC.SC2Bank
 
[쉽게 찾는 법]
 
  1. 파일 탐색기 주소창에 아래 내용을 붙여넣고 엔터
       %USERPROFILE%\Documents\StarCraft II\Accounts
  2. 오른쪽 위 검색창에 UAC.SC2Bank 검색
  3. 수정한 날짜가 가장 최근인 파일이 지금 쓰고 있는 뱅크입니다.
 
  * 내 문서가 원드라이브에 연결돼 있으면 OneDrive\문서 폴더 안에 있습니다.
 
 
■ 핸들 확인하기
--------------------------------------------------
 
뱅크 파일 경로를 보면 핸들이 두 개 있습니다. 둘 다 프로그램에 입력해야 합니다.
 
  ...\Accounts\12345678\3-S2-1-1111111\Banks\3-S2-1-2222222\UAC.SC2Bank
                        └ 내 핸들             └ 제작자 핸들
 
  * 위 숫자는 예시입니다. 본인 폴더 이름을 보고 입력하세요.
  * 한국 서버 핸들은 3-S2-1- 로 시작합니다.
 
 
■ 사용 방법
--------------------------------------------------
 
1. uac-bank-generator.html 을 더블클릭해서 엽니다.
   (크롬, 엣지, 웨일 등 아무 브라우저나 괜찮습니다)
 
2. 내 핸들과 제작자 핸들을 입력합니다.
 
3. [기존 뱅크 파일 열기]를 눌러 지금 쓰는 뱅크를 불러옵니다.
   현재 기록이 그대로 화면에 채워집니다.
   처음부터 새로 만들 거라면 [빈 세이브로 초기화]를 누르세요.
 
4. 원하는 값을 수정합니다.
   - 계급 / 전적 : 사병, 준사관, 장교 경험치를 따로 설정합니다.
                   계급을 선택하면 경험치가 자동으로 입력됩니다.
   - 모드별 기록 : 모드마다 승리 횟수와 최고 클리어 난이도(0~15)를 설정합니다.
   - 해금        : 업적, 위장, 데칼, 특성, 병과별 솔로 생존 클리어를 켜고 끕니다.
                   항목에 마우스를 올리면 해금 조건이 나옵니다.
                   검색창으로 원하는 항목을 찾을 수 있습니다.
 
5. [뱅크 만들기]를 누른 다음 [UAC.SC2Bank 저장]을 누릅니다.
 
6. 저장된 파일을 원래 뱅크 폴더에 넣어 덮어씁니다.
 
7. 게임에 들어가서 기록이 바뀌었는지 확인합니다.
 
  * 고급 값에 있는 loneWolf2 는 건드리지 마세요.
 
 
■ 처음 한 번은 서명 확인을 해주세요
--------------------------------------------------
 
게임은 뱅크를 불러올 때 서명이 맞는지 검사합니다.
서명이 틀리면 뱅크가 인식되지 않을 수 있습니다.
 
  1. 제작자 핸들을 입력합니다.
  2. 게임이 저장한 원래 뱅크를 [기존 뱅크 파일 열기]로 불러옵니다.
  3. 화면에 뜨는 메시지를 확인합니다.
 
     "서명 공식 일치 확인" → 정상입니다. 그대로 쓰면 됩니다.
     "서명 불일치"        → 제작자 핸들을 다시 확인하세요.
                            핸들이 맞는데도 불일치가 뜨면 사용하지 마세요.
 
 
■ 문제가 생겼을 때
--------------------------------------------------
 
Q. 저장한 파일 이름이 UAC.SC2Bank.txt 로 되어 있어요.
A. 끝의 .txt 를 지워주세요.
   확장자가 안 보이면 탐색기 [보기] → [파일 확장명]을 체크하세요.
 
Q. 저장 버튼이 안 눌려요.
A. [복사]를 누르고 메모장에 붙여넣은 뒤 다음과 같이 저장하세요.
   파일 이름: UAC.SC2Bank / 파일 형식: 모든 파일 / 인코딩: UTF-8
 
Q. "손상"이라고 떠요.
A. 파일이 깨졌거나 다른 사람의 뱅크입니다.
   게임이 저장한 원래 파일인지 확인하세요.
 
Q. 게임에 들어갔더니 기록이 초기화됐어요.
A. 핸들이나 서명이 맞지 않아 게임이 뱅크를 새로 만든 것입니다.
   백업해 둔 파일로 되돌리고 서명 확인부터 다시 해주세요.
 
Q. 다른 사람 뱅크도 만들 수 있나요?
A. 그 사람 핸들을 입력하면 됩니다.
   뱅크는 핸들마다 다르게 저장되기 때문에 핸들이 틀리면 게임에서 읽지 못합니다.
 
 
■ 참고
--------------------------------------------------
 
- 위장과 데칼 이름은 맵에 영어로만 들어 있어서 영어로 나옵니다.
- 모드 6번은 맵에서 쓰지 않는 칸입니다.
- 맵이 업데이트되면 뱅크 구조가 바뀔 수 있습니다.
  업데이트 후에는 정상 작동하는지 먼저 확인하세요.
 
 
■ 주의
--------------------------------------------------
 
- 맵 제작자나 블리자드에서 만든 공식 프로그램이 아닙니다.
- 뱅크 수정이 걸리면 맵 관리자가 뱅크를 초기화하거나 불이익을 줄 수 있습니다.
  사용에 따른 책임은 본인에게 있습니다.
- 덮어쓰기 전에 항상 원래 뱅크를 백업하세요.
