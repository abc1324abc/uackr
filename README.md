==============================================================
  UAC 뱅크 생성기
  Undead Assault Chronicles:KR  ·  세이브 v10 (최신 맵) 전용
==============================================================
 
스타크래프트 2 유즈맵 「Undead Assault Chronicles:KR」의 세이브 파일
(UAC.SC2Bank)을 불러와서 고치거나, 원하는 값으로 새로 만드는 도구입니다.
 
설치는 필요 없습니다. uac-bank-generator.html 파일 하나로 동작하고,
인터넷에 연결되지 않아도 쓸 수 있습니다. 입력한 내용은 내 컴퓨터
밖으로 전송되지 않습니다.
 
 
--------------------------------------------------------------
 1. 들어 있는 파일
--------------------------------------------------------------
 
  uac-bank-generator.html   생성기 본체 (더블클릭해서 실행)
  README.txt                이 설명서
 
 
--------------------------------------------------------------
 2. 시작하기 전에: 기존 뱅크 백업
--------------------------------------------------------------
 
  생성기로 만든 파일을 덮어쓰기 전에, 원래 UAC.SC2Bank 파일을
  꼭 다른 폴더에 복사해 두세요. 문제가 생기면 이 파일로 되돌리면 됩니다.
 
  뱅크 파일 위치 (윈도우)
 
    C:\Users\(윈도우 사용자명)\Documents\StarCraft II\Accounts\
      (숫자)\(배틀넷 핸들)\Banks\(제작자 핸들)\UAC.SC2Bank
 
  빨리 찾는 방법
    1) 파일 탐색기 주소창에 아래를 붙여넣고 Enter
         %USERPROFILE%\Documents\StarCraft II\Accounts
    2) 오른쪽 위 검색창에 UAC.SC2Bank 입력
    3) 수정한 날짜가 가장 최근인 파일이 지금 쓰는 뱅크입니다.
 
  문서 폴더가 원드라이브와 연결돼 있으면
    C:\Users\(사용자명)\OneDrive\문서\StarCraft II\... 에 있을 수 있습니다.
 
  맥은 아래 경로에 같은 구조로 있습니다.
    ~/Library/Application Support/Blizzard/StarCraft II/Accounts/...
 
 
--------------------------------------------------------------
 3. 경로에 나오는 두 가지 핸들
--------------------------------------------------------------
 
  뱅크 파일 경로에는 핸들이 두 번 나옵니다. 둘 다 생성기에 넣게 됩니다.
 
    ...\Accounts\12345678\3-S2-1-1111111\Banks\3-S2-1-2222222\UAC.SC2Bank
                          ~~~~~~~~~~~~~~       ~~~~~~~~~~~~~~
                          배틀넷 핸들          제작자 핸들
 
  - 배틀넷 핸들 : 내 계정. 뱅크 암호화 키가 이 값으로 만들어집니다.
  - 제작자 핸들 : 맵 제작자. 블리자드 서명을 만들 때 필요합니다.
 
  ※ 위 숫자는 예시입니다. 실제 값은 각자 폴더 이름을 보고 넣으세요.
  ※ 한국 서버 핸들은 3-S2-1- 로 시작합니다.
 
 
--------------------------------------------------------------
 4. 사용 방법
--------------------------------------------------------------
 
  1) uac-bank-generator.html 을 더블클릭해서 브라우저로 엽니다.
     (크롬, 엣지, 웨일, 파이어폭스 등 최신 브라우저)
 
  2) [01 계정]
     - 배틀넷 핸들과 제작자 핸들을 입력합니다.
     - [기존 뱅크 파일 열기]로 지금 쓰는 UAC.SC2Bank 를 불러오면
       현재 기록이 화면에 그대로 채워집니다.
     - 처음부터 만들려면 [빈 세이브로 초기화]를 누릅니다.
 
  3) [02 계급 · 전적]
     - 경험치는 사병 / 준사관 / 장교 계급 체계마다 따로 쌓입니다.
     - 계급을 고르면 그 계급의 최소 경험치가 자동으로 들어갑니다.
       경험치를 직접 입력하면 해당 계급이 표시됩니다.
     - 플레이 판수, 부활 횟수, 리콜 횟수도 여기서 고칩니다.
     - [고급 값]의 loneWolf2 는 맵이 아직 쓰지 않는 값입니다.
       불러온 값을 그대로 두세요.
 
  4) [03 모드별 기록]
     - 모드마다 승리 횟수와 최고 난이도 클리어(0~15)를 고칩니다.
     - [승리 전부 최대], [난이도 전부 15] 버튼으로 한 번에 채울 수 있습니다.
 
  5) [04 해금]
     - 업적, 위장(카모), 데칼(문양), 특수병과 특성,
       병과별 솔로 생존 클리어를 켜고 끕니다.
     - 항목에 마우스를 올리면 맵에 적힌 해금 조건이 보입니다.
     - 검색창에 이름이나 조건을 입력하면 해당 항목만 보입니다.
     - [전체 해금]은 맵에 실제로 있는 항목만 켭니다.
 
  6) [05 뱅크 생성]
     - [뱅크 만들기]를 누르면 뱅크 내용이 만들어지고,
       자동으로 다시 풀어서 무결성 검사를 합니다.
     - [UAC.SC2Bank 저장]을 눌러 파일을 받습니다.
     - 받은 파일을 2번에서 찾은 폴더의 UAC.SC2Bank 와 바꿔 넣습니다.
     - 스타2를 켜고 맵에 들어가서 기록이 바뀌었는지 확인합니다.
 
  ※ 웹 링크로 연 경우에는 파일이 UAC.SC2Bank.txt 로 저장됩니다.
     파일 이름 끝의 .txt 를 지워 주세요.
     (탐색기에서 확장자가 안 보이면 [보기] > [파일 확장명]을 켜세요.)
  ※ 저장 버튼이 안 되면 [복사]를 누르고 메모장에 붙여넣은 뒤
     파일 형식 "모든 파일", 인코딩 "UTF-8", 이름 UAC.SC2Bank 로 저장하세요.
 
 
--------------------------------------------------------------
 5. 블리자드 서명 확인 (중요)
--------------------------------------------------------------
 
  맵은 뱅크를 읽을 때 블리자드 서명(Signature)도 확인합니다.
  서명이 맞지 않으면 게임이 뱅크를 인식하지 않을 수 있습니다.
 
  생성기의 서명 계산 방식은 아직 모든 환경에서 검증되지 않았습니다.
  처음 쓸 때 아래처럼 한 번 확인하세요.
 
    1) 제작자 핸들을 입력합니다.
    2) 게임이 직접 저장한 원래 UAC.SC2Bank 를 [기존 뱅크 파일 열기]로 불러옵니다.
    3) 상태 표시를 확인합니다.
       - "서명 공식 일치 확인" → 정상입니다. 만든 뱅크가 게임에서 인식됩니다.
       - "서명 불일치"        → 제작자 핸들을 다시 확인하세요.
                                 핸들이 맞는데도 불일치라면 서명 계산 방식이
                                 다른 것이니, 만든 뱅크를 쓰지 마세요.
 
  제작자 핸들 칸을 비우면 서명 없이 만들어집니다.
 
 
--------------------------------------------------------------
 6. 지원 범위
--------------------------------------------------------------
 
  - 지원 : 최신 맵이 저장하는 세이브 v10 (UAC + UAC2 두 블록)
  - 미지원 : 예전 맵의 v7 이하 세이브
             (불러오면 "지원하지 않습니다" 안내가 나옵니다.)
  - 맵이 업데이트되어 세이브 구조가 바뀌면 이 도구도 고쳐야 합니다.
    그 전까지는 업데이트된 맵에서 쓰지 마세요.
 
  - 위장·데칼 이름은 맵 데이터에 영어로만 들어 있어서 영어로 보입니다.
  - 모드 6번은 맵에서 쓰지 않는 칸이라 "(미사용)"으로 표시됩니다.

 7. 자주 묻는 질문
--------------------------------------------------------------
 
  Q. "무결성 손상"이라고 나옵니다.
  A. 뱅크 파일이 깨졌거나, 다른 계정의 핸들이 들어간 파일입니다.
     게임이 저장한 원본 파일인지 확인하세요.
 
  Q. 다른 사람 계정용 뱅크도 만들 수 있나요?
  A. 그 사람의 배틀넷 핸들을 넣으면 만들어집니다. 뱅크는 핸들로
     암호화되므로, 핸들이 다르면 게임이 읽지 못합니다.
 
  Q. 게임에 들어갔는데 기록이 초기화됐습니다.
  A. 서명이나 핸들이 맞지 않아 게임이 뱅크를 버리고 새로 만든 경우입니다.
     백업해 둔 원래 파일로 되돌린 뒤 5번 서명 확인부터 다시 하세요.
 
  Q. 저장 횟수는 어떻게 되나요?
  A. 불러온 뱅크의 저장 횟수에 1을 더해서 저장합니다.
 
 
--------------------------------------------------------------
 8. 주의사항
--------------------------------------------------------------
 
  - 이 도구는 맵 제작자나 블리자드가 만들거나 승인한 것이 아닙니다.
  - 뱅크를 수정하는 것은 맵 제작자가 막아 둔 것을 우회하는 일입니다.
    맵 안의 관리자 기능으로 뱅크가 초기화되거나, 다른 사람과 하는
    게임에서 불이익을 받을 수 있습니다. 사용에 따른 책임은
    사용자에게 있습니다.
  - 덮어쓰기 전에 항상 원래 뱅크를 백업하세요.
